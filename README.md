# SwiftCargo Logistics

SwiftCargo Logistics is a responsive company website developed as part of **Week 2 – Task 1** of the WeIntern Full Stack Development Internship.

The project represents a fictional logistics company offering transportation, delivery, warehousing, and supply chain services.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Four-page responsive website
- Navigation bar with mobile hamburger menu
- Company and service information
- Contact form with JavaScript validation
- Responsive layouts using CSS Grid and Flexbox
- Consistent header and footer

## Website Pages

1. **Home** – Company introduction and overview of services.
2. **About** – Company background, mission, vision, and values.
3. **Services** – Details of transportation, delivery, warehousing, and supply chain services.
4. **Contact** – Customer inquiry form with input validation.

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or directly in a browser.
4. Use the navigation menu to explore the website.

## Contact Form

The contact form uses JavaScript to validate the user's name, email, phone number, service selection, and message.

The form is a frontend demonstration and does not send or store submitted information.
